# 일본 여행 안전 가이드

일본 여행을 준비하고 다니는 동안 필요한 것들을 **한국어로** 모은 앱입니다.
공항에서 시내 가는 법부터 교통패스, 관광지와 맛집, 실시간 날씨·환율·지진 정보까지
한 곳에서 봅니다.

**👉 웹으로 바로 보기 — https://abri12.github.io/japantrip/**

설치 없이 폰·PC 브라우저에서 바로 열립니다.

### 특히 신경 쓴 것

**공항에서 시내 가는 법** — 초보자가 헤매는 지점을 단계별로 풀었습니다. 어느 출구로
나가서, 무슨 표지판을 보고, 몇 분 걸리는지. 표지판은 일본어 원문(`하카타역(博多駅)`)을
같이 적어 역에서 그대로 대조할 수 있습니다. 라피트와 공항급행처럼 헷갈리는 선택지는
배차 간격·좌석·짐 두는 자리까지 비교합니다.

**노선 색 안내** — 「미도스지선」이라고만 하면 현지에서 못 찾습니다. 노선마다 색을
표시하고 **글로도 무슨 색인지 적었습니다.**

**실시간 정보** — 날씨(체감온도·시간대별 추이·자외선·바람), 환율, 지진, 기상특보를
받아옵니다. 무더위는 환경성 열중증 기준(WBGT)에 맞춰 위험도를 나눕니다.

**못 정하겠을 때** — 「어디 가지」·「뭐 먹지」에서 멈추는 순간을 위한 원판돌리기와
사다리타기. 사다리는 그림과 결과가 반드시 일치하고(지나간 길을 실제로 추적합니다),
결과 분포도 균등합니다.

## 정확성에 대해

여행 정보는 틀리면 사람이 실제로 헤매기 때문에, **확인한 것과 추정한 것을 구분해서**
적었습니다.

- 요금·운영시간·패스 조건은 공식 정보로 확인한 값입니다 (2026년 8월 기준)
- 소요 시간이나 머무는 시간은 추정치이며 그렇다고 밝힙니다
- 「주요 역」처럼 목록이 완전하지 않은 경우 완전하지 않다고 적습니다

그래도 **현지 사정은 바뀝니다.** 휴무일, 요금 인상, 노선 공사는 출발 전에 공식
사이트로 다시 확인하시는 편이 안전합니다.

## 개인정보

- **회원가입이 없고, 개인정보를 서버로 보내지 않습니다**
- 위치는 리뷰 작성 시 「그 장소에 있는지」 확인에만 쓰고, 저장하거나 전송하지 않습니다
- 뽑기·사다리 사용 횟수를 기기 안에 기록합니다. **사용자가 적은 글자는 동의해야만**
  저장하며, 사람 이름처럼 보이는 입력은 저장하지 않습니다
- 앱 안 「내 사용 기록」에서 모인 내용을 직접 보고 언제든 지울 수 있습니다

자세한 내용은 앱 안 [개인정보처리방침](https://abri12.github.io/japantrip/privacy)에
있습니다.

## 이 저장소에 대해

이 저장소에는 **웹 미리보기 빌드 결과물만** 올라가 있습니다 (`gh-pages` 브랜치).
소스 코드는 공개하지 않았습니다.

앱은 Expo(React Native)로 만들어 iOS·Android·웹을 하나의 코드로 씁니다. 웹 미리보기는
같은 코드를 브라우저용으로 내보낸 것이라, 실제 앱과 화면과 기능이 같습니다.

다만 브라우저에서 보는 것이라 이런 차이는 있습니다.

- 첫 로딩에 번들(약 1.6MB)을 받으므로 모바일 데이터에서는 잠깐 느릴 수 있습니다
- 네이티브 탭 대신 웹용 탭으로 그려져 감촉이 조금 다릅니다

## 만들면서 정한 것들

- **한국어만** — 여러 언어를 어설프게 지원하기보다 한 언어를 제대로
- **모르면 모른다고** — 확실하지 않은 정보를 그럴듯하게 적지 않기
- **부정문을 앞세우지 않기** — 「발효 중인 특보 없음」보다 지금 필요한 행동을 먼저
- **동의는 동의답게** — 수락 버튼만 강조해서 받은 동의는 동의가 아니고, 그렇게 모은
  데이터는 사실이 아닙니다. 선택지의 무게를 같게 두었습니다
