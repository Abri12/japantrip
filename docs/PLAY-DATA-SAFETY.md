# 구글 플레이 데이터 세이프티 — 작성용 대조표

Play Console 의 「데이터 안전 섹션」에 무엇을 어떻게 답할지 정리한 문서다.
**코드를 읽어서 만든 것이지 의도를 옮긴 것이 아니다.**

## 먼저 — 가장 틀리기 쉬운 것

> **「저장하지 않으니 수집이 아니다」는 틀렸다.**

Play 의 정의에서 **수집(collection)은 「기기 밖으로 나갔는가」**다. 저장 여부가
아니다. 위치를 서버로 보내 판정만 하고 버려도 **수집한 것**이다.

이 앱은 실제로 그 함정에 빠져 있었다. 개인정보처리방침이 「좌표가 기기 밖으로
나가지 않습니다」라고 적고 있었는데, 판정을 서버로 옮긴 뒤에도 그 표를 안 고쳤다.
2026년 8월에 바로잡았다.

이 문서를 만든 이유가 그거다 — **폼을 채우기 전에 코드를 확인해야 한다.**

## 수집한다고 답할 항목

| Play 분류 | 항목 | 무엇 | 필수? | 목적 | 공유? |
|---|---|---|---|---|---|
| Location | Precise location | 리뷰 인증 좌표 | 아니오 | 앱 기능 · 사기 방지 | 아니오 |
| Personal info | User IDs | 기기 id (임의 32자) | 예 | 앱 기능 | 아니오 |
| Messages | Other in-app messages | 리뷰 본문 | 아니오 | 앱 기능 | 아니오 |
| App info and performance | Crash logs | 오류 메시지·스택 | 아니오 | 앱 기능(진단) | 아니오 |
| Device or other IDs | Device or other IDs | 푸시 토큰 | 아니오 | 앱 기능(지진 알림) | 아니오 |

「공유(shared)」는 전부 **아니오**다. 제3자 분석·광고 SDK 를 하나도 안 쓴다.
오류 추적도 센트리 같은 곳이 아니라 **운영자 자기 서버**로 보낸다.

### 항목별 상세

**Precise location** — 「지금 여기 있어요」를 눌렀을 때만 읽고 서버로 보낸다.
서버가 장소 좌표와의 거리를 다시 계산한다. 리뷰에는 좌표가 안 남고 「인증됨」과
거리(m)만 남는다. 위치 위조를 막기 위해 **직전 좌표 한 건을 24시간** 보관한다
(`REVIEW_LAST_FIX_TTL_HOURS`). 백그라운드 위치는 요청하지 않는다.

- 「선택 사항(optional)」로 답한다 — 권한을 거부해도 앱의 다른 모든 기능이 동작한다
- 「임시 처리(ephemeral)」에 해당하지 않는다. 24시간 보관하는 한 건이 있기 때문이다

**User IDs (기기 id)** — 앱이 처음 실행될 때 만드는 임의의 32자다
(`src/lib/author.ts`). 하는 일은 둘뿐이다: 내 리뷰를 지울 수 있게 하고, 같은
장소에 두 번 못 쓰게 한다. **광고 식별자(AAID)나 기기 고유 식별자(IMEI·MAC)를
쓰지 않는다.** 앱을 지우면 사라진다.

- 「필수(required)」로 답한다 — 리뷰 기능을 쓰려면 반드시 생긴다

**리뷰 본문** — 사용자가 쓴 글이라 Messages 로 분류한다. 다른 사용자에게 보인다.

**Crash logs** — 오류 메시지·스택·화면 이름·플랫폼·앱 버전. **기기 id 를 안 보낸다**
(`src/lib/error-report.ts`). 그래서 「이 사용자가 세 번 겪었다」는 알 수 없고
「이 오류가 세 번 일어났다」만 안다.

**푸시 토큰** — 지진 알림을 켠 사람만. **기본은 꺼져 있고**, 안전 화면의 스위치를
켠 사람에게만 생긴다(`features/safety/push-section.tsx`). 알림 권한을 묻는 자리도
그 스위치 하나뿐이다. 토큰 + 체류 도도부현 + 알림 받을 진도를
저장한다. **기기 id 와 묶지 않는다** — 묶으면 알림 명부가 「누구인지 아는 명부」가
되기 때문이다. 알림을 끄면 지운다.

## 수집하지 않는다고 답할 항목

| 분류 | 왜 |
|---|---|
| Name · Email · Address | 회원가입이 없다 |
| Phone number | 크레딧 기능이 꺼져 있다 (아래 참고) |
| Financial info | 결제가 없다 |
| Health / Fitness | 해당 없음 |
| Photos / Videos / Audio / Files | 앱이 요청하지 않는다 |
| Contacts / Calendar | 앱이 요청하지 않는다 |
| **App activity** (검색어·화면 이동·설치 목록) | **의도적으로 안 한다** |
| Web browsing history | 해당 없음 |
| Advertising ID | 광고가 없다 |

**App activity 를 안 한다는 것이 이 앱의 결정이다.** 사용 기록 수집 기능과 동의
창, 「내 사용 기록」 화면을 모두 없앴다(`PRIVACY.md` §1-3). 뽑기·사다리타기에 적은
글자도 저장하지 않는다.

### 기기 안에만 남는 것 — 수집이 아니다

고른 도시·거점, 저장한 장소, 일정, 준비물 체크, 차단한 작성자, **여행 중 쓴 돈**.
전부 `AsyncStorage` 에만 있고 서버로 안 나간다. 앱을 지우면 함께 사라진다.
**기기 밖으로 안 나가므로 수집이 아니다.**

> ⚠ **쓴 돈은 분류가 애매해 보이지만 답은 명확하다.** Play 의 Financial info >
> Purchase history 로 읽힐 수 있는 값인데, **기기 밖으로 나가지 않으므로
> 수집이 아니다**(이 문서 머리말의 기준 그대로). 폼에는 답하지 않는다.
> 다만 언젠가 이 기록을 서버로 동기화하게 되면 **그 순간 Financial info 를
> 「수집한다」로 바꿔야 한다** — 백업 기능을 만들 때 이 줄을 다시 볼 것.

## 보안 · 삭제 관련 답변

| 질문 | 답 | 근거 |
|---|---|---|
| 전송 중 암호화되나 | **예** (조건부) | 서버를 HTTPS 로 띄워야 참이다. ⚠ 아래 참고 |
| 사용자가 삭제를 요청할 수 있나 | **예** | 리뷰는 앱에서 직접 지운다. 알림은 끄면 지워진다 |
| 데이터 삭제 요청 경로 | 앱 내 · 이메일 | 리뷰 삭제와 알림 끄기는 앱 안에서, 그 밖은 문의 |
| 독립적 보안 심사를 받았나 | **아니오** | 받은 적 없다. 받았다고 적으면 거짓이다 |
| 아동 대상 앱인가 | **아니오** | 여행 정보 앱이다 |

> ⚠ **「전송 중 암호화」는 배포 방식에 달렸다.** 서버를 평문 HTTP 로 띄우면 이
> 답이 거짓이 된다. 리버스 프록시에 TLS 를 붙였는지 **배포 전에 직접 확인하고**
> 답해야 한다. 코드가 보장해 주지 않는 유일한 항목이다.

## 크레딧을 켜면 달라지는 것

`FEATURES.credits` 가 `false` 인 동안은 위 표가 전부다. **켜면 두 줄이 는다.**

| Play 분류 | 항목 | 무엇 |
|---|---|---|
| Personal info | Phone number 또는 Email | 보상 받을 곳 |
| Financial info | Purchase history | 교환 내역 |

전화번호·이메일은 **해시해서만** 저장한다(`server/payout.mjs`). 서버에는 원본이
없고, 「같은 번호인가」만 비교한다. 다만 **Play 폼에는 그래도 「수집한다」고 답해야
한다** — 교환 요청 그 순간에는 원본이 서버를 지나가기 때문이다.

크레딧을 켤 때 이 문서와 폼을 함께 고쳐야 한다.

## 위치 — 폼이 하나 더 필요한가

**아니다.** Play Console 의 **권한 선언 폼**(Permissions Declaration Form)은
`ACCESS_BACKGROUND_LOCATION` 을 요구하는 앱에만 필요하다. 이 앱은 그것을
요청하지 않는다 — `app.json` 의 권한은 `ACCESS_COARSE_LOCATION` ·
`ACCESS_FINE_LOCATION` 둘뿐이고, expo-location 플러그인도 `locationWhenInUse`
만 켜 놓았다.

전경 위치에 필요한 것은 셋이고 **셋 다 이미 있다**:

| 요구 | 어디 | 상태 |
|---|---|---|
| 권한 요청 **전** 눈에 띄는 고지 | `features/place/review-form-section.tsx` | ✅ 하루 보관까지 밝힌다 |
| 데이터 세이프티 신고 | 이 문서 위쪽 표 | ✅ |
| 권한 없이도 앱이 도는가 | 리뷰 인증에만 쓴다 | ✅ 「선택 사항」으로 답한다 |

배경 위치를 언젠가 켜게 되면 **그때 폼이 생긴다.** 켤 일은 없어 보이지만,
켜는 사람이 이 줄을 보게 해 둔다.

## 폼을 채우기 전에 다시 볼 것

코드가 바뀌면 이 표도 바뀐다. 아래를 확인하고 폼을 손대라.

```bash
# 앱이 서버로 보내는 것 — 이 목록이 위 표와 맞나
grep -rn "body: JSON.stringify" -A12 src/lib/*.ts

# 서버가 파일에 남기는 것
grep -n "let db = " server/*.mjs

# 권한
grep -n "permissions" -A5 app.json
```
